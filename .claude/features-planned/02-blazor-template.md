# Feature: Blazor Web App Template

## Goal
Create a `dotnet new` template for a Blazor Web App with interactive render mode Auto (Server and WebAssembly), including a test project.

## Short name
`tharga-blazor`

## Notes
- This is the main template — the primary deliverable of the project
- Interactive render mode Auto = Server + WebAssembly
- Solution-level template with server project, client project, and test project
- Should follow the same patterns established by the console template
